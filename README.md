# Virtual Library INA 1G

## Sistema de Gestión de Biblioteca Virtual

Virtual Library INA 1G es un proyecto académico de una biblioteca virtual para estudiantes.

El sistema permite acceder a un catálogo de libros, buscar libros, leerlos, guardar favoritos, realizar calificaciones y reseñas, además de consultar el historial de lectura.

## Funciones principales

- Registro de usuarios
- Inicio de sesión
- Recuperación de contraseña
- Catálogo de libros
- Búsqueda de libros
- Filtros por categoría
- Favoritos
- Calificación de 1 a 5 estrellas
- Reseñas
- Historial de lectura
- Perfil de usuario
- Planes de suscripción
- Visor de lectura
- Panel de administrador
- Gestión de libros
- Gestión de categorías
- Estadísticas

## Planes

El sistema cuenta con tres planes:

| Plan | Precio | Duración |
|------|--------|----------|
| Gratis | $0.00 | Sin caducidad |
| Plata | $2.50 | 3 semanas |
| Diamante | $5.00 | 1 mes |

El Plan Diamante permite realizar descargas de los recursos disponibles.

Los pagos del sistema son solamente simulados y no representan transacciones reales.

## Catálogo

Los libros pueden buscarse por:

- Título
- Autor
- Categoría

También se pueden ordenar y filtrar los resultados.

Los libros que tengan un enlace válido de Google Drive pueden visualizarse mediante el visor integrado.

## Favoritos

Los usuarios pueden guardar libros en favoritos para encontrarlos fácilmente después.

También existe un filtro para mostrar únicamente los libros favoritos.

## Reseñas y calificaciones

Los usuarios pueden calificar los libros de 1 a 5 estrellas.

También pueden escribir una reseña de hasta 200 caracteres.

Cada usuario puede realizar una reseña por libro y posteriormente editarla.

## Historial

El sistema guarda automáticamente los libros que el usuario ha abierto.

En el perfil se muestran las últimas 20 lecturas.

## Perfil

El perfil permite consultar:

- Nombre del usuario
- Correo electrónico
- Plan activo
- Fecha de vencimiento
- Libros leídos
- Favoritos
- Reseñas
- Historial de lectura

## Administrador

El sistema cuenta con un área privada para administradores.

El administrador puede:

- Agregar libros
- Editar libros
- Eliminar libros
- Gestionar categorías
- Destacar libros
- Consultar estadísticas
- Administrar el catálogo

El acceso al área de administración está restringido a usuarios autorizados.
